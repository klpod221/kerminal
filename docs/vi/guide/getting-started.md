# Bắt đầu

Chào mừng bạn đến với **Kerminal** - terminal emulator hiện đại, hiệu suất cao kết hợp sức mạnh của terminal đầy đủ tính năng với quản lý kết nối SSH nâng cao.

## Kerminal là gì?

Kerminal được xây dựng với kiến trúc ưu tiên bảo mật sử dụng **Tauri (Rust)** cho hiệu suất native và **Vue 3** cho giao diện phản hồi nhanh. Nó cung cấp mọi thứ từ các thao tác terminal cơ bản đến các quy trình SSH phức tạp với:

- 🔐 Quản lý profile được mã hóa
- 🚇 SSH tunneling
- 🔄 Đồng bộ hóa đa thiết bị
- 🎬 Ghi và phát lại session

## Dành cho ai?

Kerminal hoàn hảo cho:

- **Lập trình viên** cần terminal đáng tin cậy với quản lý SSH
- **Kỹ sư DevOps** quản lý nhiều server và môi trường
- **Quản trị viên hệ thống** cần quy trình SSH an toàn, có tổ chức
- **Bất kỳ ai** đánh giá cao bảo mật, tổ chức và năng suất trong terminal

## Tổng quan nhanh

### Tính năng Terminal

| Tính năng | Mô tả |
|-----------|-------|
| Nhiều Tab | Làm việc với nhiều terminal cùng lúc |
| Chia màn hình | Chia không gian làm việc theo chiều ngang hoặc dọc |
| Render Canvas 2D | Render terminal tăng tốc phần cứng mượt mà |
| Hỗ trợ Unicode | Hỗ trợ đầy đủ ký tự Unicode 11 |

### Tính năng SSH

| Tính năng | Mô tả |
|-----------|-------|
| Quản lý Profile | Tổ chức kết nối theo nhóm và màu sắc |
| Xác thực Key | Hỗ trợ SSH key, certificate, v.v. |
| Port Forwarding | Local, remote và dynamic SOCKS tunneling |
| Jump Hosts | Kết nối qua nhiều bastion host |
